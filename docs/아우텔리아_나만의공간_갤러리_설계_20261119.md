# 아우텔리아: 나만의 공간 · 개인 갤러리 (2026-11-19)

## 결정된 설계
1. **독립성장**: 게임 전투/레벨/장비는 게임 내 행동으로 성장. 현실 활동 여부 때문에 필수 전투 스탯이 잠기지 않음.
2. **보상 연결**: 현실 활동은 마음 성장(PERMA 실천 기록), 꾸미기 전용 갤러리 토큰, 추억 갤러리 카드에 기록.
3. **기존 보상 보존**: 예전 저장의 `trainingPoints`와 이미 분배한 `alloc`은 그대로 보존. 앞으로 새 미션에서 전투 훈련 포인트는 지급하지 않음.
4. **부담 낮은 출석**: 하루 한 번 '오늘 방문 기록' 버튼으로 갤러리 토큰 1개. 연속 일수와 관계없이 동일 보상. 결석 페널티 없음. 방문만으로 현실 활동 수행을 요구하지 않음.
5. **기록 윤리**: 마음 성장치는 활동의 게임화된 기록이지 검증된 K-PERMA 검사 점수가 아님. 높은 만족도 보고를 유도하지 않음. 각 캐릭터 갤러리는 해당 저장 칸에 포함됨.

## 초기 구현 (별도 개발 브랜치)
- 게임 메뉴에 **나만의 공간** 추가. 전용 화면 내 가상 전시실과 최근 활동 3개 액자, 누적 기록 최대 30개 목록.
- 개인 갤러리 저장소 `S.gallery` (tokens/unlocked/selected/attendance). 오래된 저장에서는 기본값으로 초기화.
- 현실 미션 1회 완료 → 갤러리 토큰 +1 (한 미션 중복 지급 금지). 전투 `trainingPoints`는 더 이상 증가하지 않음.
- 출석 버튼 → 하루 한 번 +1 토큰, 미방문 불이익 없음.
- 토큰으로 액자·화분·등불·깃발 4종 해금. 전시/숨기기 선택 가능.
- 기존 활동 자기평가(도전·의미·만족)는 개인 갤러리에도 기록. 자유 소감 원문을 갤러리 화면에 자동 공개하지 않음.
- 새 갤러리는 **메뉴 UI 기반의 기능성 시제품**. 전용 횡스크롤 이동 맵, 배경 원화, 사진 업로드 기능은 아직 없음.

## 다음 제작 단계
- 실제 '나만의 공간' 배경 원화 16:9(하단 18% 평평한 바닥), 기존 반사실 수채풍 통일.
- 캐릭터가 방에 들어와 좌우로 이동하고 액자를 Space로 조사하는 전용 맵.
- 갤러리 이미지(현재는 상징과 텍스트)·사진 등록 기능은 사용자 동의·개인정보 및 저장 용량 정책을 검토한 뒤 진행.
- 이용자가 자신의 경험을 선택해 배치할 수 있는 다중 액자 배치·공간 확장.
- 단계적 현실 미션(발견→선택→변형→창조)·자기설계 활동 반영 후 기록/토큰 체계 확장.
- 스토리 및 접근성 검토: 방문 일수 수치는 통계로만 표시, 강박적 연속 로그인 보상은 도입하지 않음.

## 미해결 설계 결정
- 갤러리 방문 보상이 외재적 동기만 강화하지 않도록: 과도한 출석 알림·연속 출석 경쟁·놓친 날 손실은 배제
- 기존 `trainingPoints` 소지자에 대한 처분: 현행에서는 보존·사용 가능. 강제 토큰 변환은 하지 않음
- 실제 사진 업로드, 공유 기능, 데이터 연구 활용은 별도 명시적 동의가 생기기 전까지 비활성
