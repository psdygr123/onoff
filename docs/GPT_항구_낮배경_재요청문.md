## 왜 다시 그리나
게임 안 항구(포르투 노바) 배경 2장이 **붉은 노을 하늘**입니다. 항구는 '새 출발·희망'의 장소인데 해 지는 분위기라 맞지 않습니다. 프롤로그에서 이미 받은 **`port.webp`(푸른 하늘·하얀 구름·푸른 바다·붉은 지붕 항구 마을)** 의 분위기로 통일합니다.

|---|---|---|---|---|
| E1 | `harbor_day.png` | 포르투 노바 항구 (마을, 안전지대) | 가로 1600×720 비율(약 20:9) | 높음 |
| E2 | `harbor_road_day.png` | 항구 길 (사냥터, 좌우로 긴 길) | 가로 2450×720 비율(약 17:5) | 높음 |

- 첨부(그림체·색감 기준): 프롤로그 `port.webp`(밝은 낮 항구), 기존 `harbor.webp`·`harbor_road.webp`(**구도·건물·배 위치만 참고**, 색감은 따르지 않음).
- 색 말고 구도는 가능한 한 기존 그림과 같게 합니다(게임 속 발판·NPC 위치가 이미 맞춰져 있음).

## [E 공통 규칙] — 매 대화 맨 앞에 그대로 붙여넣기
```
당신은 2D 횡스크롤 판타지 게임의 **배경 일러스트 1장**을 그립니다. 아래 규칙은 모두 필수입니다. 어긴 부분이 있으면 고쳐서 다시 그린 결과만 보여 주세요.
1. 시간대는 **맑은 낮(오전~한낮)**. 하늘은 **선명한 파랑 + 하얀 뭉게구름**, 바다는 **맑은 청록~파랑**에 잔물결 반짝임. **노을·석양·주황색 하늘·붉은 하늘 금지.** 희망차고 활기찬 느낌.
2. 그림체: 첨부한 port.webp와 같은 **밝은 애니메이션풍 수채 느낌**, 부드러운 채색, 얇은 윤곽선. 3D·사진 느낌 금지.
3. 사람·동물(갈매기는 하늘에 아주 작게 2~3마리까지 가능)·글자·숫자·간판 글씨·로고·워터마크·UI·테두리 없음.
4. **아래쪽 약 30%는 캐릭터가 걷는 평평한 바닥**(나무 부두 판자 또는 흙·돌길). 바닥 위에 큰 사물을 두지 않습니다(막히지 않게). 바닥과 배경이 자연스럽게 이어지게.
5. 첨부한 기존 그림의 **큰 건물·배·수평선의 좌우 위치를 유지**합니다.
6. 상용 게임·애니메이션 배경과 닮지 않게.
```

## E1 항구 (harbor_day.png)
```
[이번 그림] 포르투 노바 부두. 기존 harbor.webp와 같은 구도로, 낮 풍경으로 다시 그립니다.
- 왼쪽: 돌벽에 붉은 기와지붕, 아치형 초록 문이 둘 달린 창고 건물. 꽃덩굴과 화분, 나무 상자·통. 햇빛을 받아 밝고 선명한 색.
- 오른쪽: 큰 목선 두 척이 정박. 하얀 돛은 말아 올려 햇빛에 환하게. 부두 계단이 배로 이어짐.
- 가운데~뒤: 푸른 바다, 먼 수평선에 연한 푸른 산과 작은 해안 마을(붉은 지붕). 하늘은 파랑에 하얀 뭉게구름.
- 바닥: 밝은 갈색 나무 판자 부두(햇빛 아래 따뜻한 색, 노을 반사 없음).
```

## E2 항구 길 (harbor_road_day.png)
```
[이번 그림] 항구로 이어지는 바닷가 길. 기존 harbor_road.webp와 같은 구도로, 낮 풍경으로 다시 그립니다. 좌우로 매우 긴 그림(약 17:5).
- 왼쪽에서 오른쪽으로: 초록 나무와 하얀 꽃덤불, 사이프러스 나무, 낮은 나무 울타리와 돌담, 오른쪽 끝에 붉은 지붕 창고 건물(항구 입구).
- 뒤쪽: 반짝이는 푸른 바다, 멀리 푸른 산등성이와 해안 마을. 하늘은 파랑+하얀 구름, 해는 화면에 직접 그리지 않아도 됩니다.
- 바닥: 밝은 흙길+돌길, 오른쪽 끝은 나무 부두 판자로 이어짐.
- **좌우 가장자리 끝**은 이어 붙여도 어색하지 않게 비슷한 높이·색의 풀숲으로.
```

## [E 확인 목록]
1. 하늘이 파랗고 노을색(주황·붉은색)이 전혀 없는가? 2. 바닷물이 푸른색이고 반짝이는가?
3. 글자·사람·로고가 없는가? 4. 아래 30%가 비어 있는 평평한 바닥인가?
5. 기존 그림과 건물·배 위치가 같은가? 6. 프롤로그 port.webp와 같은 그림체·색감인가?

## [E 재요청 문장]
- 노을색이 남았을 때: `하늘과 구름의 주황·붉은 기운을 모두 없애고, 선명한 파랑 하늘+하얀 뭉게구름으로 바꿔 다시 그려 주세요. 구도는 유지.`
- 바닥에 물건이 있을 때: `아래쪽 30%의 사물을 모두 지우고 평평한 바닥만 남겨 다시 그려 주세요.`
- 그림체가 다를 때: `첨부한 port.webp와 같은 밝은 애니메이션풍 수채 그림체로, 구도는 유지해 다시 그려 주세요.`

## 참고: 같은 문제가 있을 수 있는 다른 배경
아르케아 마을(plaza)·숲길(forest_road)도 노을빛입니다. 아르케아는 '축제 날 저녁' 설정이라 그대로 두고, 숲길은 이야기상 해 질 무렵이어도 무리가 없어 **일단 요청하지 않습니다**(원하시면 낮 버전을 추가).
