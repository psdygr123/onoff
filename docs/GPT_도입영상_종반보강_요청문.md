## [공통 규칙] — 매 대화 맨 앞에 그대로 붙여넣기
당신은 2D 판타지 게임의 도입 영상에 쓸 **배경 일러스트 1장**을 그립니다. 아래 규칙은 모두 필수입니다. 어긴 부분이 있으면 고쳐서 다시 그린 결과만 보여 주세요.
1. 화면비 **16:9 (가로)**, 원본처럼 약 1672×941 이상.
2. **그림체는 첨부한 01_creation_tapestry.png와 같게**: 오래된 벽화·직물 태피스트리, 거친 삼베 결, 금실 윤곽선. 갈색·올리브·크림·금빛이 바탕, 어둠은 짙은 남색.
3. **글자·숫자·기호 문자·로고·테두리 없음.**
4. **얼굴이 보이는 인물 없음.** 사람은 얼굴 없는 작은 실루엣뿐. 신은 사람 모양(얼굴·눈코입·손발)으로 그리지 않습니다.
5. **피·상처·시체·불·폭발·사람을 해치는 장면 없음.** 폭력은 빛과 그림자의 충돌로만. 화면 전체가 하얗게 터지는 섬광 금지.
6. 상용 작품의 특정 장면·캐릭터를 닮지 않게. 3D·사진 느낌 금지.
7. 영상에 이어 붙이므로 하늘은 기본적으로 **왼쪽 금빛(빛), 오른쪽 남색(어둠)** 기준(그림에서 따로 정하면 그쪽을 따름).

## N6 영웅의 진격 — 첨부: 01, N4b, N4
장면: 다섯 영웅이 어둠을 향해 나아가는 순간.
- N4b의 **다섯 실루엣(방패·별 지팡이·활·망토·닻 창)을 같은 모습으로**, 이번에는 **오른쪽(어둠)을 향해 걷거나 달려가는 자세**로.
- 실루엣 뒤에서 **금빛 거대한 물결이 따라와 밀어 주듯** 흐르고, 오른쪽에서는 남색 구름 물결이 마주 옵니다. N4의 소용돌이 구름 무늬 계열.
- 영웅은 화면 아래 3분의 1의 능선 위에 작게, 하늘이 화면의 대부분. 사람이 해를 입는 장면, 무기가 부딪히는 장면 없음.

## N7 빛의 신의 침묵 — 첨부: 01, 02, N1
장면: 승리 이후의 고요. 신이 모습을 감춤.
- 하늘 가운데 높은 곳에 **N1과 같은 금실 빛의 고리가, 훨씬 작고 희미하게** 떠 있고, 고리를 **엷은 금빛 구름이 서서히 덮어** 가는 모습(고리의 아래 절반이 이미 구름에 가려짐).
- 하늘 전체는 어둠이 걷힌 따뜻한 금빛·크림 색(02의 마지막 상태). 남색은 거의 없고 별 몇 개만 남음.
- 아래에는 고요한 땅(굽이치는 강, 언덕, 멀리 아주 작은 마을 지붕 몇 개). 사람 없음.
- 쓸쓸함보다 **조용한 평화와 약간의 허전함**.

## N8 영웅들의 귀향 — 첨부: 01, N4b
장면: 영웅들이 각자의 고향으로 흩어짐.
- 새벽 언덕 위 **하나의 길이 다섯 갈래로 갈라지는 지점**. 얼굴 없는 실루엣 다섯이 각자 다른 갈래 길로 **뒷모습**으로 걸어갑니다(N4b와 같은 소품: 방패·별 지팡이·활·망토·닻 창이 보이게).
- 길은 서로 다른 방향의 멀리 있는 작은 마을·산·바다 쪽으로 이어집니다(바다 쪽 길 하나 포함).
- 하늘은 따뜻한 금빛 새벽. 해가 왼쪽에서 올라옴. 평화롭고 약간 쓸쓸한 분위기.
