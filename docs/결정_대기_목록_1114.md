## 2. 정한 것 (11-14)
- 마스크 피부 수정 병합 완료(main 03b5790).
- 스토리: 오르비스 = 5영웅 가문 중 하나(궁수 계열), 금속 조각 = 증거물, 기본 무기 = 검, 19세 이상 표현 기준(불필요한 장면은 연출하지 않고 표현만).
- 피로도: 쌓이는 방식(0에서 시작, 스킬로 상승, 가득 차면 스킬 불가, 기본 공격은 무관). 회복 = 선택형 '쉼' 현실 미션 + 은화 휴식. 주간 초기화는 안전장치로 켜 둠.
- 마음 스탯: PERMA 5개, 현실 미션 완료 시 오름. **전투 효과 없음(확정)**. 모험일지의 '마음 기록' 탭에 기록(스탯 창에서는 뺌).
- 메이플스토리 참고: 분위기와 시스템. 드롭·보스·퀘스트 형식.
- 드롭: 떨어진 아이템을 직접 줍는 방식. **구현 완료**(몬스터별 드롭 표, 바닥에 떨어짐, Space로 줍기, 90초 뒤 사라짐, 희귀 장비 1.5% 안팎). 재료는 **상인에게** 판매·제작: 포르투 노바의 잡화상인(재료 사기·팔기, 회복약 구매), 무기상인(재료와 은화로 희귀 장비 제작). 상인 그림 4장 적용 완료.
- 퀘스트: 메인은 스토리 기반. 서브는 **B안(인물별 짧은 이야기)**: 본편과 상관없이 세계관 몰입·이스터에그 역할, 깨다 보면 세계관의 새 사실을 알게 되고, 그 퀘스트로만 얻는 아이템·훈장을 줌.
- 신전 완공 소리: 종 대신 따뜻하고 낮은 신비로운 울림(A안).
- 도입 영상: **자막만 사용(내레이션 없음)**, 정지 그림 + 코드 연출로 시안을 먼저 만들고, 움직임이 부족한 컷만 힉스필드를 쓰는 순서. 그림체는 신화 파트 벽화·태피스트리풍, 현재 마을은 수채풍. 구성은 신·갈라짐·땅·탐욕·대전쟁·영웅·승리·비석·마을·축제 10컷(약 55초). GPT 그림 중 신화 6장(N1·N2·N3·N4·N4b·N5) 수신. 힉스필드 구독은 신청 사유서 작성 단계.

## 3. 지금 필요한 결정·할 일
1. [결정] 소리: 실제 소리 파일을 구할지(후보 링크는 대화에 있음, 라이선스는 사용자가 확인) / 합성음 유지. 몬스터·타격·발소리가 특히 어색하다는 피드백. 도입 영상의 배경음악·환경음도 같이 결정.
2. [결정] 피로도 수치(회복량·은화 가격·하루 횟수·주간 초기화 유지 여부)와 드롭 수치(확률·판매가·제작 재료량)는 모두 임시. 플레이하며 조정.
3. [제가→사용자] 도입 영상 시안(v1) 검토 후 부족한 컷 판단. 남은 그림: **R1(신전을 게임 신전으로 교체한 벽화 마을), R2(같은 신전의 수채 축제 마을)**. GPT가 신전 참고 파일(`temple_done.webp`, `plaza.webp`)을 못 받아 만들지 못함. 지금 시안에는 기존 03·04를 임시로 씀(신전 모양이 게임과 다름). 자막 대본(임시)은 시안에 입혀져 있으니 문장 확정 필요.
4. [결정] 힉스필드 구독 여부. 신청 사유서 작성 완료. 공식 요금: Plus 월 $49, 월 1,000 크레딧(2026년 10월 확인 표기). 크레딧 소모량·워터마크·한국어 음성 품질은 미확인. 영상은 코드 연출만으로도 가능하므로 대전쟁 컷 등 꼭 필요한 컷만 쓸지 판단.
5. [제가] 다음 개발 순서(제안): ~~드롭 체계~~(완료) → 퀘스트 종류 확장(수집·배달·호위·조사·선택·목공) → 1막 스토리 퀘스트(포르투 노바·방파제·바르샤·검은 골짜기·제페토) → 보스(1막 최종, 주 1회 재도전) → 인물형 서브 퀘스트(B안) 소수. 그림 요청은 1막 퀘스트 직전에 일괄 정리.
6. [결정] 서브 퀘스트 인물 후보와 이스터에그 사실·훈장 목록(제가 초안 작성 후 선택).
7. [제가] 현실 미션 목록은 임시 10개 + 쉼 4개. 확장 필요. 상인 이름의 "(임시)" 표기, 재료 이름도 정식 이름 필요.
