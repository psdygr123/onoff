# 아우텔리아 도입 영상 — 그림체 비교용 테스트 이미지 요청문 (GPT용)

## 목적
도입 영상의 **그림체를 정하기 위한 비교 그림 3장**입니다(같은 장면을 A·B·C 세 가지 그림체로). 정식 키프레임은 선택 후에 다시 요청합니다. **한 번에 1장씩** 요청하고, 3개 대화(또는 3번 요청)로 받으세요.

## 공통 규칙 (매번 맨 앞에 붙여넣기)
당신은 2D 판타지 게임의 도입 영상에 쓸 **배경 일러스트 1장**을 그립니다. 아래 규칙은 모두 필수입니다.
1. 화면비 **16:9 (1280×720)**, 가로 장면.
2. **글자·숫자·로고·워터마크·말풍선·테두리 없음.**
3. **얼굴이 보이는 인물 없음.** 사람이 있다면 아주 작은 뒷모습이나 실루엣만.
4. 피·상처·무기를 휘두르는 장면 없음. 잔잔하고 신비로운 분위기.
5. 상용 게임·애니메이션·영화의 특정 장면이나 캐릭터를 닮지 않게.
6. 장면: **"태초의 신이 빛과 어둠 사이에 땅을 펼친 순간"**. 하늘은 왼쪽이 밝은 새벽빛, 오른쪽이 고요한 밤. 그 사이에 넓고 고요한 대지가 펼쳐져 있고, 중앙에 작은 빛 한 줄기. 아주 멀리 작은 산과 계곡의 윤곽.
7. 색감: 따뜻한 갈색·올리브·크림 + 하늘은 옅은 금빛과 짙은 남색.

## 그림체 (3가지 중 해당하는 것만 추가)
- **A 벽화·태피스트리풍**: 오래된 벽화나 직물 자수 그림처럼 평면적이고 장식적인 무늬, 거친 질감, 금실 같은 빛 표현.
- **B 수채 그림책풍**: 얇은 갈색 윤곽선, 부드러운 수채 번짐, 따뜻한 종이 질감. (게임 배경과 같은 계열)
- **C 그림자극풍**: 종이를 오려 만든 듯한 검은 실루엣 층과 뒤에서 비치는 빛, 단순한 색면.

## 직접 확인 목록
1. 글자·로고가 없는가? 2. 얼굴이 보이는 인물이 없는가? 3. 왼쪽 밝음·오른쪽 어둠·중앙의 땅이 보이는가? 4. 선택한 그림체가 맞는가? 5. 16:9인가?

## 재요청 문장
- 글자가 있을 때: `그림 안의 모든 글자와 로고를 지우고, 나머지 구도와 그림체는 바꾸지 말고 다시 그려 주세요.`
- 그림체가 다를 때: `A(또는 B, C) 그림체 설명을 그대로 따르고, 구도는 유지해 다시 그려 주세요.`
