# 아우텔리아 주인공 색 바꾸기용 "부위 표시 그림" 요청문 (GPT용 · 그림 1장당 1요청)

## 왜 필요한가
캐릭터 만들기에서 **머리색·옷색을 고르게** 하려고 합니다. 게임이 그림의 색만 보고 머리·조끼를 구분하면 얼굴·목 가장자리에 색이 번지고 조끼가 얼룩덜룩해졌습니다(실험 확인). 머리·피부·바지·장화가 모두 갈색이라 색만으로는 구분이 안 됩니다. 그래서 **기존 그림을 그대로 두고, 바꿀 부위만 단색으로 칠한 표시용 그림**을 받습니다. 게임은 이 표시 그림에서 부위를 뽑아내고, 원본 그림의 명암은 그대로 둔 채 색만 바꿉니다. **표시용 그림은 게임에 직접 쓰지 않습니다.**

## 가장 중요한 한 가지
**원본과 한 픽셀도 어긋나면 안 됩니다.** 그림 크기, 프레임 위치, 인물 위치, 포즈를 **원본 그대로** 유지해야 합니다. 새로 그리지 말고 **원본을 그대로 두고 지정 부위만 단색으로 덮어 칠하는** 작업입니다. 그림을 다시 그리거나, 크기를 바꾸거나, 인물을 옮기면 실패입니다.

## 사용 방법
1. **대화(채팅) 1개당 그림 1장**만 요청합니다(여러 장을 한 번에 하면 일부가 어긋납니다).
2. 각 대화의 **맨 처음**에 [공통 규칙]을 통째로 붙여넣고, **원본 PNG 1장을 첨부**한 뒤 [개별 요청] 한 줄을 덧붙입니다.
3. 첨부 파일은 함께 보내드린 `아우텔리아_색상마스크_원본11장.zip`의 PNG입니다(흰 배경으로 바꾼 사본이며 크기는 원본과 같습니다).
4. 결과가 오면 [직접 확인 목록]으로 점검하고, 통과한 것만 Claude에게 전달해 주세요. 부위 추출·정렬 검사·게임 적용은 Claude가 합니다.
5. 우선순위: **P0** = 01~06(본편·프롤로그 전신), **P1** = 07~11(초상화).

## [공통 규칙] — 매 요청 맨 앞에 그대로 붙여넣기

당신은 첨부한 게임 캐릭터 그림을 **편집**합니다. 새로 그리는 것이 아니라, 지정한 부위만 **단색으로 덮어 칠하는** 작업입니다. 아래 규칙은 **모두 필수**이고, 하나라도 어기면 실패입니다. 그리기 전에 규칙을 모두 확인하고, 어긴 부분이 있으면 고쳐서 다시 만든 결과만 보여 주세요. 변명이나 긴 설명은 필요 없습니다. 그림 1장만 보내 주세요.

**칠할 부위와 색 (이 색 그대로, 그라데이션·명암·질감 없이 평평한 한 가지 색)**
- **머리카락 전체** (앞머리·옆머리·뒷머리·묶은 머리·삐죽 솟은 머리카락, 포니테일 포함) → 순수 **마젠타 #FF00FF**
- **조끼(겉옷)** (조끼 몸판과 칼라, 가슴 끈 장식 제외) → 순수 **시안 #00FFFF**
- **바지** (무릎 아래 접힌 부분 포함) → 순수 **연두 #00FF00**
- 위에 적지 않은 부위(피부, 눈, 눈썹, 셔츠, 벨트, 장갑, 장화, 장식, 윤곽선)는 **원본 그대로 두고 한 픽셀도 바꾸지 않습니다.**

**위치와 크기 (가장 중요)**
1. 출력 그림의 **가로·세로 크기와 비율이 첨부 원본과 완전히 같아야** 합니다. 크기를 바꾸거나 여백을 늘리거나 잘라내지 마세요.
2. 시트(여러 프레임이 가로로 늘어선 그림)면 **프레임 개수, 간격, 순서, 각 인물의 위치와 자세를 원본 그대로** 둡니다. 프레임을 합치거나 재배치하지 마세요.
3. 칠한 면의 **가장자리는 원본의 해당 부위 경계(윤곽선 안쪽)에 정확히 맞춥니다.** 윤곽선을 넘어 바깥(배경, 피부, 다른 옷)으로 번지지 않게 하고, 부위 안쪽에 **칠하지 않은 틈이 남지 않게** 합니다. 머리카락 사이 빈틈이나 조끼 단 가장자리도 해당 부위면 모두 칠합니다.
4. 배경은 첨부한 **흰색(#FFFFFF) 그대로**입니다.

**절대 하지 말 것**
- 인물·자세·표정·옷 모양을 다시 그리거나 바꾸기, 확대·축소, 위치 이동, 좌우 반전
- 마젠타·시안·연두를 위 세 부위 **밖에** 쓰기(다른 부분이 이 색으로 보이면 안 됩니다)
- 그림자, 바닥선, 글자, 숫자, 워터마크, 테두리, 설명 문구 추가
- 칠한 면에 명암, 하이라이트, 무늬 넣기(평평한 한 가지 색이어야 부위를 뽑아낼 수 있습니다)

## [직접 확인 목록] — 받은 그림이 아래를 **모두** 만족해야 통과
1. 그림 크기와 비율이 원본과 **같은가?** (이미지 정보나 파일 크기로 확인. 다르면 바로 재요청)
2. 원본과 **겹쳐 놓고 번갈아 보았을 때** 인물·프레임 위치와 자세가 움직이지 않는가?
3. 머리카락이 **빈틈 없이 마젠타 한 가지 색**으로 칠해졌는가? 얼굴·목·귀 피부에 마젠타가 번지지 않았는가?
4. 조끼가 **시안 한 가지 색**으로 칠해졌고, 셔츠(소매·깃)·벨트에 번지지 않았는가?
5. 바지가 **연두 한 가지 색**으로 칠해졌고, 장화·장갑에 번지지 않았는가?
6. 칠하지 않아야 할 부위(피부·눈·셔츠·벨트·장갑·장화·윤곽선)가 **원본 그대로**인가?
7. 시트면 **모든 프레임**에 같은 방식으로 칠해졌는가? (일부 프레임만 빠지는 경우가 많습니다)
8. 마젠타·시안·연두가 세 부위 밖에서 보이지 않는가? 글자·그림자·테두리가 없는가?

## 자주 틀리는 부분과 재요청 문장 (그대로 복사해서 사용)
- 그림 크기·비율이 바뀌었을 때: `출력 크기가 원본(가로 ○○○ × 세로 ○○○)과 다릅니다. 같은 크기로, 인물을 옮기지 말고 부위만 다시 칠해 주세요.`
- 인물이 다시 그려졌거나 어긋났을 때: `인물이 원본과 다르게 다시 그려졌습니다. 새로 그리지 말고, 첨부한 원본을 그대로 둔 채 지정 부위만 단색으로 덮어 칠해 주세요.`
- 색이 피부·셔츠로 번졌을 때: `칠한 면이 [피부/셔츠/장화]로 번졌습니다. 윤곽선 안쪽의 [머리카락/조끼/바지]만 칠하고, 나머지는 원본 그대로 되돌려 주세요.`
- 일부 프레임이 빠졌을 때: `[n]번째 프레임이 칠해지지 않았습니다. 6프레임 모두 같은 방식으로 칠해 주세요.`
- 칠한 면에 명암이 들어갔을 때: `칠한 면에 그림자와 하이라이트가 있습니다. 평평한 한 가지 색(#FF00FF / #00FFFF / #00FF00)으로만 칠해 주세요.`
- 재요청할 때 공통: **인물은 바꾸지 말고** 틀린 부분만 고치라고 꼭 써 주세요.

## 이 요청이 막힐 때의 대안 (Claude가 판단)
이미지 생성 도구는 **픽셀 단위로 정확히 맞추는 것이 서툴러서**, 시트가 가로로 길수록 어긋날 수 있습니다. 03~06번이 두 번 재요청해도 크기가 맞지 않으면, 시트를 **프레임 1개씩 잘라서** 요청하거나(Claude가 잘라 드립니다), **색 조합을 완성본으로 받는 방식(B안)** 으로 바꿉니다. 이 경우 Claude가 말씀드립니다.

## 전달할 파일 이름
받은 그림의 파일명 앞에 `mask_`를 붙여 주세요(예: `mask_03_pro_player_m_locomotion.png`). 파일 형식은 png가 좋습니다. 표시용 그림은 게임 폴더에 넣지 않고 Claude가 부위만 뽑아 쓴 뒤 보관합니다.

## 적용 계획 (Claude 작업, 그림이 오면)
1. 마젠타·시안·연두 단색 면을 뽑아 **부위 표시(마스크) 3장**으로 변환, 원본과 겹쳐 어긋남 검사(어긋나면 재요청).
2. 게임에서 부위 색만 바꾸는 방식으로 적용(원본 명암 유지). 캐릭터 만들기 화면에 **머리색 팔레트 · 조끼색 팔레트 · 바지색 팔레트** 선택 추가(색 수는 처음에 6~8종).
3. 저장 정보에 선택한 색 저장, 본편·프롤로그·초상화·미리보기에 모두 반영.
4. 피부와 윤곽선은 건드리지 않으므로 **얼굴이 변색되는 일은 없습니다.** 한계는 머리카락 하이라이트의 밝은 부분(색이 옅어 보일 수 있음)입니다.
