# 아우텔리아 GPT 요청문: 엿듣기·추격 컷 여주인공 버전 4장 (2026-11-25)

남자 주인공으로 이미 받은 컷 4장(relay_chase / relay_trapped / relay_rope / relay_hide)을 **주인공만 여성 모험가로 바꾼 같은 구도·같은 그림체**로 다시 받습니다. 주인공 외의 모든 것(배경·용병·변형 여우·리프트·노인 제페토·조명·색감)은 첨부 원본과 동일하게 유지합니다.

사용: 컷마다 새 채팅(또는 같은 채팅에서 순서대로)에 **원본 컷 1장을 첨부**하고 아래 [공통 지시]를 보냅니다. 결과 파일명은 `relay_chase_f.webp`, `relay_trapped_f.webp`, `relay_rope_f.webp`, `relay_hide_f.webp`(게임이 여자 주인공일 때 자동으로 이 이름을 찾습니다. 없으면 그림 없이 큰 글씨만 나옵니다).

## [공통 지시]
첨부한 그림과 **완전히 같은 구도·배경·인물 배치·조명·색감·수채화풍**으로, **남자 주인공 한 명만 20대 여성 모험가로 바꿔** 다시 그려 주세요.
- 여성 주인공: 짧은 갈색 단발~중단발 머리(헝클어진 느낌), 첨부 속 남자 주인공과 **같은 옷**(밝은 셔츠 + 가죽 조끼 + 멜빵 + 등짐), 같은 표정·동작.
- 그 외 인물(용병·제페토 등)과 배경·소품은 **바꾸지 말 것**.
- 가로 1536 × 세로 1024 이상, 원본과 같은 비율.
- 금지: 글자·숫자·로고·워터마크·UI, 구도 변경, 선정적 표현.

## 컷별 확인
1. chase: 달리는 모습, 뒤에서 횃불 용병과 변형 여우가 쫓아옴.
2. trapped: 절벽 끝 리프트 앞, 몸을 낮춘 채 돌아보는 모습.
3. rope: 아래쪽에서 올려다보는 주인공(오른쪽 아래), 위에서 제페토가 밧줄을 끊음.
4. hide: 바위틈에서 제페토가 주인공의 입을 막고 '쉿' 하는 장면(여성 주인공으로).
