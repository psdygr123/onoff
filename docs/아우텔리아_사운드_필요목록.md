## 2. 필요한 효과음(SFX)
- **이동·전투**: 걸음, 점프, 착지, 검 휘두름, 적중, 적 피격, 플레이어 피격, 적 사망, 보스 등장
- **상호작용**: 대화 넘김(짧은 틱), 선택지 선택, 문·상자 열기, 아이템 획득, 장비 착용, 포션 사용, 퀘스트 수락/완료
- **성장**: 레벨 업, 전직, 스킬 사용
- **메뉴**: 메뉴 열기/닫기, 버튼 클릭, 경고/오류
- **컷신용**: 망치질(대장간), 종소리, 폭발·충돌, 불꽃, 군중 환호, 비명 대신 완곡한 긴장음

## 3. 필요한 환경음(루프)

## 4. 정해야 할 것 (결정 필요)
1. 음원 제작 방식: 생성형 음악 서비스 / 직접 제작 / 무료·유료 음원 중 무엇으로 할지
2. **이용 조건 확인**: 생성형 서비스를 쓸 경우 해당 서비스의 약관(상업 이용·공개 배포 가능 여부)을 곡마다 기록
3. 파일 형식·용량 기준: BGM은 mp3 128kbps 이하, 곡당 3MB 안팎 권장(모바일에서 아우텔리아는 PC 전용이라 PC 기준)
4. 소리 시끄러움 방지: 처음 재생 음량 낮게, 설정에서 끄기(현재 있음), 필요하면 BGM/효과음 따로 조절 추가
5. 정신건강 서비스 특성상 급격한 큰소리·공포 연출은 피하는 기준 정하기(습격 장면 포함)
