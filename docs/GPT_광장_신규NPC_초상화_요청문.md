# 아우텔리아 프롤로그 광장 신규 NPC 2명 — 초상화 + 대기 자세 요청문 (GPT용 · 인물 1명당 1요청)

## 왜 필요한가
축제 광장에서 마을길에서 이미 만난 인물(나이 든 주민·축제 어린이)이 또 나오던 문제를 고치기 위해, 광장에는 **광장에서만 만나는 인물 2명**을 새로 세웠습니다. 동작 그림(시트)은 이미 있어서 **초상화(대화창 얼굴)**와 **대기 자세(가만히 서 있는 모습)**만 새로 필요합니다. 지금은 초상화가 없어 기존 주민 얼굴이 대신 나옵니다.

| 인물 | 시트 파일 | A 초상화 | B 대기 자세 |
|---|---|---|---|
| 먼 마을에서 온 할머니 | `villager_g_actions` | 필요 (`pt_pro_traveler`) | 필요 (`villager_g_idle`) |
| 꽃 심부름 온 사내아이 | `villager_l_actions` | 필요 (`pt_pro_florist`) | 필요 (`villager_l_idle`) |

총 **4장**(초상화 2 + 대기 자세 2). B(대기 자세)는 없어도 게임은 동작합니다(지금은 환호 동작으로 서 있음). 급하면 A만 먼저 받으세요.

## 사용 방법
1. **대화 1개당 인물 1명**: [A 초상화] → [B 대기 자세]를 **같은 대화에서 이어서** 요청합니다(얼굴·옷이 같아야 하므로).
2. 매 대화 맨 앞에 아래 [공통 규칙]을 통째로 붙여넣고, **첨부 이미지는 그 인물의 시트**(`villager_g_actions.png` 또는 `villager_l_actions.png`) + 그림체 기준용 기존 초상화 1장(`pt_pro_baker`)입니다.
3. 받은 그림을 [직접 확인 목록]으로 점검한 뒤 Claude에게 전달해 주세요(마젠타 제거·크기 맞춤·게임 반영은 Claude가 합니다).

## [공통 규칙] — 매 대화 맨 앞에 그대로 붙여넣기

당신은 2D 횡스크롤 게임용 **인물 그림**을 그립니다. 아래 규칙은 **모두 필수**입니다. 그리기 전에 규칙을 모두 확인하고, 어긴 부분이 있으면 고쳐서 다시 그린 결과만 보여 주세요. 변명이나 긴 설명은 필요 없습니다. 한 번에 그림 1장만 보내 주세요.

1. **첨부한 시트의 인물과 완전히 같은 사람**을 그립니다. 얼굴·머리·옷·소품·체형·색을 바꾸지 마세요. 새 디자인을 만들지 말고 **첨부 시트를 그대로 옮겨 그리는 것**이 목표입니다.
2. 배경은 **마젠타(#FF00FF) 한 가지 색**으로만 꽉 채웁니다. 인물의 옷·머리·피부·소품에는 마젠타, **분홍, 보라, 자주 계열 색을 절대 쓰지 않습니다**(배경을 지울 때 같이 지워집니다). 붉은색은 벽돌색·적갈색만 씁니다.
3. 그림체: 첨부한 시트와 같은 **밝은 애니메이션풍**, **얇은 갈색 윤곽선**(끊긴 곳 없이 닫힘), 부드러운 채색, 천의 주름과 질감을 세밀하게.
4. **절대 하지 말 것**: 그림자·바닥선·땅·풀·반사·빛 번짐·배경 그라데이션, 글자·숫자·워터마크·로고·UI·테두리·말풍선, 다른 인물·동물·배경 사물·이펙트, 상용 게임/애니메이션 캐릭터와 닮은 디자인, 3D 렌더링·사진 질감·형광색.

## [A 초상화] 규격
- 정사각형 **1024×1024**, 가슴 위 반신, 정면~3/4 각도, 배경은 마젠타 단색.
- 원형 틀에 잘리므로 **머리 꼭대기 위로 여백 8%**, 어깨까지 보이게.
- 소품(지팡이 등)은 보이면 그리되, 얼굴이 가려지지 않게.

## [B 대기 자세] 규격
- 같은 인물이 **차분하게 서 있는 자세 2프레임**(① 정지 서기, ② 숨을 쉬는 듯 어깨·소품이 아주 조금 다른 서기)을 **1열 × 2행**(위/아래)으로 한 장에. 모두 **완전한 옆모습, 오른쪽을 봄**, 전신이 잘리지 않게, 마젠타 배경, 두 프레임이 닿지 않게 간격을 충분히.
- **환호·박수·달리기 아님.**
- 키(발바닥~머리 꼭대기)는 **첨부한 시트의 프레임과 같은 크기**로 맞춥니다.

## [개별 요청]

### 1. 먼 마을에서 온 할머니 (시트 `villager_g_actions`)
- 파일명: 초상화 `pt_pro_traveler`, 대기 자세 `villager_g_idle`
- 첨부 시트 그대로: 70대, 흰 머리를 둥글게 말아 올린 쪽머리, 주름진 온화한 얼굴, **짙은 남색 자수 외투**, 크림색 술 달린 숄, 회색 치마, **나무 지팡이**, 갈색 신발.
- 표정: **호기심 많고 흐뭇한 미소**(처음 와 본 큰 마을과 신전을 구경하는 손님).
- 초상화: 지팡이 손잡이를 쥔 손이 가슴 아래에 살짝 보여도 좋습니다.
- 대기 자세: **지팡이를 한 손으로 짚고** 다른 손은 몸 옆에 자연스럽게 서 있기. 허리가 약간 굽은 체형 유지.
- 주의: 첨부 시트의 숄 술 한쪽에 분홍빛이 살짝 도는 부분이 있습니다. **숄 술·자수에는 분홍·보라를 쓰지 말고 크림색·황토색**으로 그려 주세요.

### 2. 꽃 심부름 온 사내아이 (시트 `villager_l_actions`)
- 파일명: 초상화 `pt_pro_florist`, 대기 자세 `villager_l_idle`
- 첨부 시트 그대로: 7~8세, 짧은 검은 머리(약간 헝클어짐), **밝은 청색 반팔 셔츠**, 갈색 반바지, 허리에 작은 가죽 주머니, 무릎에 헝겊, 샌들.
- 표정: **신나서 활짝 웃는 얼굴**(축제날).
- 초상화: 어깨와 셔츠 깃, 허리 주머니는 보이지 않아도 됩니다.
- 대기 자세: 두 손을 몸 옆에 두고 **발끝을 살짝 들썩이는 듯** 서 있기(① 서기, ② 아주 조금 더 높이 선 모습). 뛰거나 손을 번쩍 드는 동작은 안 됩니다.

## [직접 확인 목록] — 받은 그림이 아래를 **모두** 만족해야 통과
1. 초상화·대기 자세가 **첨부 시트와 같은 사람**인가(얼굴·머리·옷·소품·체형·색)?
2. 초상화 머리 위에 여백이 있고 어깨까지 보이는가?
3. 대기 자세가 완전한 옆모습·오른쪽·전신이며 환호/달리기가 아닌가? 두 프레임이 닿지 않았는가?
4. 키가 첨부 시트의 프레임과 같은 크기인가?
5. 배경이 마젠타 단색이고 인물에 분홍·보라 계열이 섞이지 않았는가(할머니 숄 술 주의)? 글자·그림자·바닥이 없는가?
6. 그림체(얇은 갈색 윤곽선, 밝은 애니메이션풍)가 기존 `pt_pro_baker` 초상화와 같은 계열인가?

## 재요청 문장 (그대로 복사)
- 다른 사람처럼 나왔을 때: `첨부한 시트의 인물과 얼굴·머리·옷·소품이 같아야 합니다. 디자인은 바꾸지 말고 첨부 시트와 똑같이 다시 그려 주세요.`
- 환호·달리기 자세일 때: `차분하게 서 있는 자세여야 합니다. 두 손을 몸 옆에 자연스럽게 두고, 완전한 옆모습으로 다시 그려 주세요. 디자인은 유지합니다.`
- 분홍·보라가 섞였을 때: `인물에 분홍·보라 계열 색이 있습니다. 같은 디자인에서 그 부분만 크림색 또는 황토색으로 바꿔 다시 그려 주세요.`
- 배경에 그림자·바닥이 있을 때: `배경은 마젠타(#FF00FF) 한 가지 색뿐이어야 합니다. 그림자와 바닥을 모두 지우고, 인물 디자인은 바꾸지 말고 다시 그려 주세요.`
- 공통: **디자인은 바꾸지 말고** 틀린 부분만 고치라고 꼭 써 주세요. 안 쓰면 매번 다른 사람이 나옵니다.
