# 아우텔리아 GPT 오브젝트 요청문: 하차 장부 (yard_ledger) (2026-11-25)

대상: 용병 하차장(잠입 맵) 오른쪽 끝 리프트 아래의 **조사 지점 "하차 장부"**. 지금은 임시로 부서진 궤짝 그림(`trace_crate.webp`)이 나와 장부로 보이지 않습니다. 정식 그림이 오면 `assets/object/yard_ledger.webp`로 넣으면 자동 교체됩니다(`js/story1.js`의 `ob_yard_ledger`).
사용 순서: 대화 맨 처음에 [공통 머리말]을 붙이고 요청을 보냅니다. 첨부(그림체 기준): `trace_crystal_crate.webp`(같은 계열 오브젝트). 결과는 Claude가 배경 제거·규격 변환(webp)을 합니다.

## [공통 머리말]
첨부한 이미지와 같은 그림체(얇은 갈색 윤곽선, 질감이 살아 있는 수채풍 채색)로 2D 횡스크롤 게임용 **오브젝트 1점**을 그려 주세요.
1. **배경은 단색 마젠타(#FF00FF)**, 그림자·바닥 없이 오브젝트만. 가장자리는 또렷하게.
2. 옆(정면에 가까운 3/4) 시점, 가로 약 3 : 세로 약 2.5 비율, 가능한 큰 해상도.
3. 한 방향 광원(왼쪽 위), 따뜻한 빛과 차가운 그림자.
**금지**: 사람·몬스터, **글자·숫자·알파벳**(장부의 줄은 글자 없이 가는 선과 점·가로줄 표시만), 로고, 워터마크.

## 하차 장부
**낡은 나무 책상(탁자) 위에 펼쳐진 두툼한 장부.** 용병단이 하차한 짐을 기록하는 장부입니다.
- **책상**: 거칠고 오래된 목탁자, 한쪽 모서리에 쇠 보강대. 상판은 얼룩과 긁힌 자국, 잉크 자국.
- **장부**: 두꺼운 가죽 표지의 큰 장부가 펼쳐져 있고, 양쪽 면에 **칸과 가로줄이 그어진 표**(글자 없이 선과 짧은 획 표시만), 종이는 누렇게 변색, 모서리가 닳음. 장부 위에 **불도장으로 찍힌 '검은 물결' 무늬**(굵은 물결 3~4줄을 겹친 표식)가 표지 가장자리에 보이게.
- **소품(책상 위)**: 깃펜이 꽂힌 잉크병 1개, 짧은 양초 또는 작은 랜턴 1개(호박색 불빛), 끈으로 묶은 종이 뭉치 1개, **검은 결정 조각 1~2개**(각진 검은 돌, 안쪽에 희미한 붉은 핏줄)를 장부 옆에.
- **책상 아래/옆**: 작은 나무 상자 1개를 책상 옆에 붙여 놓아도 됩니다(검은 물결 불도장 표식이 옆면에).
- 어둠 세력의 검은 고리 표식은 넣지 않습니다.
