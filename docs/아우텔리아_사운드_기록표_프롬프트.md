# 아우텔리아 사운드 기록표 + 제작 프롬프트 (임시 음원 → 정식 교체)

작성: 2026-11-11 · 상태: 제작 전(전부 미제작) · 상위 문서: `아우텔리아_사운드_필요목록.md`
이 문서는 ① 지금 게임에 들어 있는 소리와 교체 대상, ② 소리마다 입력할 문장(프롬프트), ③ 만든 기록을 적는 표입니다. 같은 내용의 표 파일(`아우텔리아_사운드_기록표.csv`)은 구글 시트·엑셀에서 열어 직접 기록하실 수 있습니다.

## 0. 방침
- 지금 만드는 소리는 **임시**입니다. 효과음·환경음은 Fish Audio, BGM은 Suno로 시도합니다.
- 정식 단계(공개·연구)에서는 **유료 구독 상태에서 다시 만들어 전부 교체**합니다. 무료로 만든 소리는 상업 이용이 허용되는지 확인되지 않았으므로 정식 단계에 그대로 쓰지 않습니다. (Suno 무료 플랜 곡은 Suno 소유이며 비상업 용도로 허용, 유료 구독 중 만든 곡은 사용자 소유라고 안내되어 있음 — 2026-09 수정 안내문 기준)
- 파일 이름: `temp_` + ID + 장면, 예) `temp_BGM-04_festival.mp3`, `temp_SFX-02_plank.mp3`. 정식 교체본은 `temp_`를 뗀 이름으로 바꿉니다.
- 올려 주실 때 **제작 서비스·요금제(무료/유료)·제작일·고른 번호**를 CSV에 적어 주세요. 비어 있으면 제가 "출처 미확인"으로 표시합니다.
- 소리 크기 원칙: 급격한 큰 소리, 공포·충격 연출은 피합니다(이 서비스는 정신건강 목적). 습격·이별 장면 소리도 "긴장·슬픔은 있되 놀라게 하지 않는" 수준으로 주문했습니다.
- 반복이 필요한 소리(BGM·환경음)는 끝과 시작이 이어지게 제가 가공합니다. 효과음은 3종씩 만들어 번갈아 쓰면 덜 지루합니다("— 3종" 표시).
- 프롬프트는 영문 기준으로 적었습니다. 서비스가 한국어를 잘 알아들으면 한국어로 바꿔 쓰셔도 됩니다(어느 쪽이 나은지는 확인하지 못했습니다).

## 3. 기록 방법
1. `아우텔리아_사운드_기록표.csv`를 시트로 열어, 만든 소리마다 상태(제작 완료)·제작일·요금제·서비스·파일명·약관 확인 여부를 적습니다.
2. 파일은 위 이름 규칙으로 저장해 올려 주세요. 제가 음량을 맞추고 루프를 가공한 뒤 `games/autelia/assets/audio/`에 넣고 장면에 연결합니다.
3. 연결된 소리는 이 표의 "상태"에 "연결 완료"로 바꿔 기록합니다.
4. 정식 단계에서는 "교체 대상(임시)=예"인 모든 줄을 유료 구독 상태에서 다시 만들어 교체합니다. 교체가 끝난 줄은 "교체 완료"로 바꿉니다.
