```

- 몸과 예복 전체가 **짙은 남색~검은 보라**. 소매 끝 문양과 가장자리는 **은빛**으로 아주 조금.

- 얼굴·형태는 빛의 신 시안과 똑같은 방식(a 베일 / b 흐릿한 윤곽 / c 어둠 덩어리 윤곽).
```
