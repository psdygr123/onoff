## 0. 한눈에 보기 (결론)

- **시제품은 "눈으로 보고 눌러볼 수 있는 단계"까지 왔습니다.** 홈페이지, 회원가입(체험용), 로그인, 마이페이지, 게임 5칸, 게임 실행 연결이 동작합니다.
- **아우텔리아는 프롤로그(8장면)까지 구현**되어 있고 자동 시험을 통과했습니다. 본편(1~10레벨)은 임시 콘텐츠 수준이며 그림·톤이 프롤로그와 다릅니다.
- **사람이 직접 한 플레이 시험은 아직 없습니다.** 모든 확인은 자동 시험과 화면 캡처 기준입니다.
- **디렉터 결정이 필요한 항목은 6개**(7장)이며, 그중 연구 동의 관련 2건은 "보류"로 정해졌습니다.
- **모바일 정책**: 휴대폰·태블릿에서는 **인내의 미로와 마율만 실행** 가능, 아우텔리아는 PC 전용 안내가 표시됩니다.

## 2. 플랫폼(온앤오프 사이트)

- **구조**: 정적 사이트. 게임은 iframe으로 열고, 플랫폼과 게임은 메시지로만 대화합니다(이름·이메일 등 개인정보는 게임에 전달하지 않음).
- **회원가입 4단계**: 계정 → 기본정보 → 이용 목표 → 동의. 만 19세 이상 확인 포함.
- **동의 항목**
  - [필수] 서비스 이용약관
  - [필수] 개인정보 수집·이용 (세부 내용 펼쳐보기)
  - [선택] 심리학 연구 자료로 활용 (연구 범위 미정, 확정 시 안내·철회 가능 문구)
- **마이페이지**: 동의 현황(연구 목적 활용 포함) 표시, 게임 이어하기/시작.
- **현재 공개 방식**: GitHub 저장소 기반 시제품. **정식 서버 오픈 시 공개 방식은 변경 예정**(디렉터 결정 6번: 유지).
- **한계**: 실제 계정 인증·서버 저장 없음. 화면 상단에 "시제품" 안내를 상시 표시합니다.

## 3. 아우텔리아

- 프롤로그 「빛의 축제, 그리고 잿더미」: 도입 글 카드 4장 + 8장면.
- 캐릭터 설정(남/여 모습 + 닉네임 2~8자) → 대사 속 호칭에 조사까지 자동 반영.
- 정식 그림 반영(배경·인물·장애물·초상화·불·연기), NPC 대화 4명(농부·신관·악사·서기) 초상화, 대기 자세 6종.
- 자동 시험 통과: 캐릭터 설정 36, 건너뛰기 6, 장애물 3, 상태 24, 선택 NPC, 전체 플레이스루.
- **남은 것**: 도입 글은 **임시 초안**(기획 정식 문장 필요), 몬스터 그림, 본편 톤 통일, 소리, 스토리 문서 후반부(포르투 노바 이후) 미구현.

## 4. 임시 게임 2종

| 게임 | 상태 | 유의점 |
|---|---|---|
| 마율 (Mind & Calm) | 플랫폼 연결·ready 신호 확인 | 외부 CDN(tailwind·lucide·Google Fonts) 의존 → 인터넷이 막히면 모양이 깨질 수 있음. 진행 저장 없음 |
| 인내의 미로 (Mindful Maze) | 시작·과속 충돌·재시도·플랫폼 연결 확인, **터치 조이스틱 추가** | **3단계 완주 가능 여부는 미확인**. 대표 이미지는 임시(추후 결정). 소개문은 "설계 의도이며 효과를 보장하지 않습니다"로 완화 |

## 5. 이미지 제작 현황 (GPT 제작 → Claude 반영)

- 반영 완료: 프롤로그 정식 그림, NPC 다양화 10종, 신규 NPC 초상화·대기 자세, 게임 카드 3종, **배너 3종**.
- 요청문 작성 완료·그림 대기: 몬스터.
- 보류: 인내의 미로 전용 대표 이미지(디렉터 결정 대기), 출시 예정 2칸은 같은 이미지를 임시 반복 사용 중.

## 6. 모바일 대응 (이번 갱신)

**정책(디렉터 지시)**: 모바일에서 게임 실행은 인내의 미로·마율만 가능. 홈페이지·회원가입 등은 모바일에서도 정상 동작.

- **판별 방식**: 화면 폭이 아니라 "터치가 주 입력인 기기(pointer: coarse)"인지로 판단. 좁게 줄인 PC 창은 PC로 취급합니다.
- **아우텔리아(PC 전용)**: 터치 기기에서 카드 버튼이 "PC에서 이용"(비활성)으로 바뀌고 안내 문구 표시, 소개 화면의 시작 버튼 차단, 주소로 직접 진입해도 안내 화면 표시, 마이페이지 버튼 교체.
- **홈의 "시작하기"**: 터치 기기에서는 실행 가능한 첫 게임(마율)으로 연결.
- **인내의 미로**: 화면 폭에 맞춰 캔버스 축소, 하단 가상 조이스틱(살살 밀면 천천히 — 이 게임의 "속도 조절" 취지에 맞춰 아날로그 입력), 안내 문구가 기기에 따라 전환. 키보드 조작은 그대로 유지.
- **플랫폼 화면**: 게임 영역(iframe) 높이를 모바일에서 세로로 확대.
- **확인한 것**(390px 폭, 터치 에뮬레이션): 홈·게임·소개·로그인·가입 4단계(제출 포함)·마이페이지·약관·처리방침·문의·인내의 미로 실행 화면에서 가로 넘침 없음, 오류 없음. 조이스틱 입력으로 공이 실제로 이동함.
- **확인하지 못한 것**: 마율의 모바일 모양(검증 환경에서 외부 CDN이 차단되어 확인 불가), 실제 휴대폰 기기 테스트, 태블릿.

## 9. 아직 확인하지 못한 것 (한계)

1. 사람이 직접 한 플레이 시험(전부 자동 시험).
2. 실제 휴대폰 기기 테스트.
3. 마율의 모바일 화면(외부 CDN 의존).
4. 인내의 미로 3단계 완주 가능 여부, 모바일 조이스틱으로 난이도가 적절한지.
5. GitHub Pages 실제 공개 주소에서의 동작.
6. 아우텔리아 설정·그림 불일치: 스토리는 아르케아를 "계곡 사이 마을"로, 정식 배경 그림은 바다가 보이는 언덕 마을로 표현(글은 계곡으로 맞춰 둠).
