# 아우텔리아 포르투 노바 상인 NPC 2명 — 초상화 + 전신 그림 요청문 (GPT용 · 인물 1명당 1대화)

작성: Claude · 2026-11-14 · 상태: 제안안. 게임에는 기존 인물 그림을 임시로 붙여 둔 상태이며, 이 그림이 오면 교체합니다.

## 왜 필요한가
포르투 노바에 상인 NPC 2명을 세웠습니다. 재료를 팔고 회복약을 사는 **잡화상인**, 장비를 만들어 주는 **무기상인**입니다. 지금은 임시로 기존 인물 그림(마을 사람, 전직 담당)을 쓰고 있어서 다른 NPC와 똑같이 보입니다.

| 인물 | 게임 이름 | 필요한 그림 | 게임 파일 |
|---|---|---|---|
| 잡화상인 | `porto_general` | A 초상화, B 전신 | `pt_porto_general`, `porto_general` |
| 무기상인 | `porto_smith` | A 초상화, B 전신 | `pt_porto_smith`, `porto_smith` |

총 **4장**(초상화 2 + 전신 2). 급하면 A(초상화)만 먼저 받으세요. 전신은 임시 그림으로도 동작합니다.

## 사용 방법
1. 인물 1명당 **대화 1개**: [A 초상화] → [B 전신]을 **같은 대화에서 이어서** 요청합니다(얼굴·옷이 같아야 하므로).
2. 매 대화 맨 앞에 [공통 규칙]을 붙여넣고, 그림체 기준으로 **기존 NPC 그림 2장**(`char/smith.webp`, `char/villager_a.webp`)과 기존 초상화 1장(`portrait/smith.webp`)을 첨부합니다.
3. 받은 그림은 [직접 확인 목록]으로 점검해 Claude에게 전달해 주세요(마젠타 제거·크기 맞춤·게임 반영은 Claude가 합니다).

## [공통 규칙] — 매 대화 맨 앞에 그대로 붙여넣기

당신은 2D 횡스크롤 판타지 게임용 **인물 그림**을 그립니다. 아래 규칙은 **모두 필수**입니다. 어긴 부분이 있으면 고쳐서 다시 그린 결과만 보여 주세요. 변명이나 긴 설명은 필요 없습니다.

1. 인물 디자인은 아래 [인물 설명]을 따릅니다. **첨부한 기존 NPC 그림과 다른 사람**이어야 하고(얼굴·머리·옷·체형 모두), 그림체만 같게 합니다.
2. 배경은 **마젠타(#FF00FF) 한 가지 색**으로만 꽉 채웁니다. 인물의 옷·머리·피부·소품에는 마젠타, **분홍, 보라, 자주 계열 색을 절대 쓰지 않습니다**(배경을 지울 때 같이 지워집니다). 붉은색은 벽돌색·적갈색만 씁니다.
3. 그림체: 첨부한 NPC 그림과 같은 **밝은 애니메이션풍**, **얇은 갈색 윤곽선**(끊긴 곳 없이 닫힘), 부드러운 채색, 천과 가죽의 주름과 질감을 세밀하게. 분위기는 따뜻한 항구 도시의 상인.
4. **절대 하지 말 것**: 그림자·바닥선·땅·풀·반사·빛 번짐·배경 그라데이션, 글자·숫자·워터마크·로고·UI·테두리·말풍선, 다른 인물·동물·배경 사물·이펙트, 상용 게임/애니메이션 캐릭터와 닮은 디자인, 3D 렌더링·사진.
5. **19세 이상 게임이지만 이 그림은 일상적인 인물입니다.** 피·상처·위협적인 자세·노출 없음. 무기 소품은 칼집에 꽂거나 벽에 걸듯 들고 있는 정도만.

## [인물 설명]

### 잡화상인 (porto_general)
- 40대 후반 여성 행상인. 둥글고 부드러운 얼굴, 짧게 땋아 올린 **연한 밤색 머리**, 웃는 눈.
- **짙은 청록색 앞치마**와 크림색 블라우스, 허리에 작은 **동전 주머니 여러 개**, 한쪽 어깨에 **커다란 보따리 가방**(알록달록한 천 조각이 삐져나옴). 손에는 **작은 놋쇠 저울** 또는 병 몇 개가 든 바구니.
- 체형은 아담하고 따뜻한 인상. 기존 `villager_a`(갈색 원피스 여성)와 헷갈리지 않게 **색은 청록색·크림·놋쇠색**을 쓰고, 머리 모양을 다르게.

### 무기상인 (porto_smith)
- 50대 초반 남성. 각진 얼굴, **은회색 짧은 수염**, 한쪽 눈썹에 오래된 흉터(작고 옅게). 표정은 무뚝뚝하지만 친절한 장인.
- **짙은 녹색 가죽 조끼**와 걷어 올린 소매의 회색 셔츠, 목에 두른 **두건**, 어깨에 **칼집 두 개를 가로질러 멘 벨트**(무기는 모두 칼집 안), 허리에 줄과 작은 도구 몇 개.
- 기존 `smith`(전직 담당: 황토색 앞치마·머리띠)와 헷갈리지 않게 **색은 녹색·회색·가죽 갈색**, 머리띠 대신 두건, 체형은 키가 크고 마른 편.

## [A 초상화] 규격
- 정사각형 **1024×1024**, 가슴 위 반신, 정면~3/4 각도, 배경은 마젠타 단색.
- 원형 틀에 잘리므로 **머리 꼭대기 위로 여백 8%**, 어깨까지 보이게.
- 소품(저울, 칼집 끈 등)은 보이면 그리되 얼굴이 가려지지 않게.
- 게임에는 512×600으로 줄여 넣습니다.

## [B 전신] 규격
- **같은 인물의 전신 1장**, 완전한 옆모습, **오른쪽을 봄**, 발끝부터 머리 꼭대기까지 잘리지 않게, 차분하게 서 있는 자세(손에 소품). 마젠타 배경.
- **세로로 긴 비율(약 2:3)**, 인물 주변 여백은 좁게. 게임에는 220×330으로 줄여 넣습니다.
- 키는 첨부한 기존 `smith.webp`, `villager_a.webp`와 비슷한 크기감으로. 환호·달리기·공격 자세 아님.

## 직접 확인 목록
1. 첨부한 기존 NPC와 **다른 사람**으로 보이는가?
2. 배경이 마젠타 단색이고, 인물에 **마젠타·분홍·보라 계열**이 없는가?
3. 그림자·바닥선·글자·로고가 없는가?
4. 초상화의 얼굴과 전신의 얼굴·옷이 **같은 사람**인가?
5. 전신이 **오른쪽을 보는 옆모습**이고 발끝과 머리가 잘리지 않았는가?
6. 무기는 칼집 안에 있고 위협적인 자세가 아닌가?

## 재요청 문장
- 기존 NPC와 비슷할 때: `첨부한 기존 NPC와 얼굴·머리·옷 색이 겹치지 않도록 [인물 설명]에 적은 색과 머리 모양을 더 분명히 하고 다시 그려 주세요.`
- 마젠타·분홍 계열이 섞였을 때: `인물에서 마젠타·분홍·보라·자주 계열 색을 모두 다른 색(갈색·적갈색·남색)으로 바꾸고 나머지는 유지해 다시 그려 주세요.`
- 그림자·바닥선이 있을 때: `인물 아래 그림자와 바닥선을 지우고 배경을 마젠타 단색으로만 채워 다시 그려 주세요.`
- 전신이 옆모습이 아닐 때: `같은 인물을 완전한 옆모습(오른쪽을 봄), 전신이 잘리지 않게 다시 그려 주세요.`
