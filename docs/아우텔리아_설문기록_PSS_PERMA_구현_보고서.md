# 아우텔리아 설문 기록(PSS·K-PERMA) 구현 보고서 (2026-11-14)

## 한 줄 요약
한국판 PSS(10문항)와 K-PERMA(23문항) 응답·채점·저장·CSV 내보내기를 모험일지 "마음 기록" 탭에 구현했습니다. **기능은 기본 꺼짐**이며, 사용 허가·연구 승인이 정리되기 전에는 이용자에게 켜지 않습니다.

## 켜는 법
- 주소 끝에 `?survey=1` (예: `.../games/autelia/index.html?survey=1`)
- 또는 `?dev=1` 로 연 뒤 F2 개발 패널 → "설문 기능 켜기". 같은 패널에서 PSS·PERMA CSV 내려받기, 설문 기록 지우기.
- 게임 안에서: 모험일지(J) → 마음 기록 탭 → 아래쪽 "설문 기록".

## 사용한 척도와 출처
| 척도 | 판본 | 출처 | 비고 |
|---|---|---|---|
| PSS | 한국판 지각된 스트레스 척도 10문항 | 박준호·서영석(2010), CMU 공개본 PDF (2010년 출처) | 한국 대학생 타당화(N=312, 368). 원본 PDF와 문항 10개·지시문 글자 단위 일치 확인(`tools/verify_scale_text.py`) |
| PERMA | 한국판 플로리시 척도(K-PERMA) 23문항 | 심교린·김완석(2019), 예술심리치료연구 15(4), 319-340 (2019년 출처) | 한국 대학생·성인 N=249 타당화. 논문 표 1을 그림으로 보고 옮기고 글자 구성도 대조 |

이전에 GPT가 준비한 패키지의 PERMA 번역(Hwang, 2014년 출처)은 사용하지 않습니다(문항 순서·표현이 다르고 한국 표본 타당화가 확인되지 않음). 두 판을 섞지 않았습니다.

## 채점
- **PSS**: 응답 0~4. 논문 표 1 기준 최종 10문항에서 긍정적 지각 5문항(PDF 4~8번)을 역채점. 부정적 지각 = 1·2·3·9·10번 합(0~20), 긍정적 지각 = 4~8번 원점수 합(0~20), 합계(역채점 후) 0~40은 참고용. 논문은 하위척도를 따로 쓰기를 권하며 총점은 "부정적 지각 + 긍정적 지각의 결여"로 해석하라고 설명함. 점수 기준선 없음.
- **K-PERMA**: 응답 0~10. P(3·13·22), E(2·10·17), R(8·19·21), M(7·9·20), A(1·5·15) 각 3문항 평균. 참고 항목 N(4·14·16), H(6·12·18), L(11), T(23). PERMA 평균 = 15문항 평균(논문 표 2 값과 일치). 원개발자 안내의 "전반적 웰빙(15문항+종합적 행복감 16문항 평균)"은 참고 열로 따로 기록. 역채점 없음, 부정정서·외로움은 평균에 섞지 않음.
- 미응답은 0이 아니며, 한 문항이라도 비면 점수를 만들지 않음.

## 화면·저장
- 시점 3개(시작 전/마친 뒤/추적)를 데이터에 phase로 저장. 같은 척도·시점은 한 번만 제출, 제출 후 수정 불가(수정 규칙은 연구계획 확정 후).
- 응답 초기값 없음, 뒤로·수정 가능, 중간에 닫으면 임시 저장(이어하기), 제출 전 확인.
- 설문 응답은 게임 저장과 다른 키(`autelia.survey`)에 보관. 피로도·은화·훈련 포인트·마음 스탯·HP에 영향 없음(시험으로 확인).
- 결과 화면: 판정·기준선 없음, 이전 응답과의 차이만 표시(같은 문항·채점 버전끼리만). 설정 `showResultToParticipant`로 결과 비공개 전환 가능.
- CSV: 척도별 별도 파일, 한 행 = 참여자×시점×척도, 원응답/역채점 후 값 구분, 빈칸과 0 구분, UTF-8(BOM), 수식 삽입 방지. 미완료 임시 저장은 점수를 비워 포함.

## 아직 확인·결정이 필요한 것
1. **사용 허가**: 두 척도 모두 `rightsStatus: permission_not_recorded`. PSS는 ePROVIDE/번역자, PERMA는 원개발자 안내(연구·비영리, 출처 표기)와 K-PERMA 번역자 확인 필요. 이 저장소는 공개이므로 문항 공개 범위도 함께 판단.
2. **연구 동의·IRB**: 동의 흐름과 연결 전(`consentVersion` 비움). 실제 이용자 데이터 수집은 승인 이후.
3. **K-PERMA 응답 양끝 설명**: 논문에 없음. 지금은 0~10 숫자만 표시하고 "0은 가장 낮은 쪽, 10은 가장 높은 쪽" 안내를 척도 상자 밖에 게임 문구로 둠(원문 아님). 원개발자 영어판의 문항별 양끝 설명을 번역해 쓸지는 결정 필요.
4. **참여자 ID**: 이 기기에서 만든 가명 ID. 플랫폼 계정·연구 대상자와의 연결은 서버·연구 설계 후.
5. **저장 위치**: 아직 이 기기(localStorage). 서버 저장과 CSV 일괄 수집은 서버 연결 이후.
6. PSS 회상기간은 원문대로 "지난 한 달". 주간 측정을 하더라도 회상기간을 바꾸지 않음(시행 간격은 연구 일정으로 관리).

## 시험
`tests/survey_pss.js`(24), `tests/survey_perma.js`(17): 문항·역채점 번호, 채점 독립 계산, 0 응답, 미완료·중복·범위 밖, 비교 규칙, 게임 자원 불변, 저장 분리, CSV(열·수식 방지·빈칸), 모바일 폭. 기존 시험(feedback 17, regression, mind_stats 11, fatigue 13, drops 25)도 재통과. 사람이 직접 한 화면 확인은 아직 없음.
