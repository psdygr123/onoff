# 아우텔리아 GPT 배경 요청문: 정보상 바르샤의 공방 내부 (jandari_shop) (2026-11-22)

대상: 1막(포르투 노바) 잔다리 골목 안쪽 「정보상의 공방」 실내. 지금은 임시로 무기점 실내 그림(`weapon_store.webp`)을 쓰고 있어 장면과 어울리지 않습니다. 정식 그림이 오면 `story1.js`의 `bg_barsha_shop` 경로(`assets/bg/barsha_shop.webp`)만 바꾸면 됩니다.
사용 순서: 대화 맨 처음에 [공통 머리말]을 붙이고 요청을 보냅니다. 첨부(그림체 기준): `alley.webp`(잔다리 골목: 공방 문과 쇼윈도), `general_store.webp`(실내 그림체 기준). 결과는 Claude가 규격 변환과 맵 좌표 조정을 합니다.

## [공통 머리말]
첨부한 이미지와 같은 그림체(얇은 갈색 윤곽선, 부드러운 수채풍 채색)로 가로형 2D 횡스크롤 게임의 **배경 일러스트 1장**을 그려 주세요.
1. 가능한 가장 큰 해상도, 가로 비율 **1500:720**(약 2.08:1). 
2. **깊이가 느껴지는 3층 구성**: 앞쪽(가장자리의 기둥·선반 모서리·늘어진 천, 어둡고 선명), 가운데(인물이 지나는 무대, 가장 자세히), 뒤쪽(벽과 창으로 옅어지는 안쪽).
3. 한 방향의 분명한 광원(오른쪽 창으로 들어오는 오후 빛과 작업등)과 따뜻한 빛·차가운 그림자의 대비.
4. 나무·종이·유리·금속·천의 질감을 충분히 묘사하고 반복되는 무늬를 피합니다. 소품 크기는 사람 키 기준.
5. 화면 **아래 약 18%는 평평한 수평 나무 바닥 띠**이고, 바닥 띠의 윗선이 화면 위에서 82% 지점에서 또렷해야 합니다. 바닥 중앙은 인물이 설 수 있게 비워 둡니다.
**금지**: 사람·인물, 글자·숫자·기호 문자(지도 위 지명도 글자 없이 선과 점으로만), 로고, UI, 워터마크, 별과 초승달.

## 정보상의 공방 내부 (barsha_shop)
**골목에서 문을 닫고 들어온, 길드 장부에 없는 정보를 모으는 비밀 공방.** 어둡고 아늑하되 어딘가 수상한 분위기.
- **왼쪽 끝 15%**: 방금 들어온 **아치형 나무문의 안쪽 면**(문은 닫혀 있고, 빗장과 작은 유리창으로 골목의 따뜻한 불빛이 살짝 새어 들어옴). 문 옆 벽에 걸린 외투와 작은 등.
- **가운데~오른쪽(무대)**: 화면 중앙보다 약간 오른쪽에 **큰 나무 작업대(탁자)**. 인물이 작업대 뒤에 서 있을 수 있도록 작업대 뒤쪽 벽은 비워 둡니다(작업대 상판 높이가 화면 위에서 약 60% 지점). 작업대 위에는 **돋보기가 달린 검은 결정 조각 한 점**(각진 검은 유리 같은 돌, 안쪽에 희미한 붉은 핏줄)과 **구겨진 양피지 지도**(글자 없이 선과 붉은 점만), 잉크병, 컴퍼스, 놋쇠 렌즈.
- **벽**: 선반에 병·두루마리·상자, 코르크판에 실로 이어 붙인 쪽지와 지도(글자 없이 선·점만), 천장에 매달린 놋쇠 천구의와 톱니바퀴 장식(골목 쇼윈도의 장치와 같은 모티프).
- **오른쪽 15%**: 안쪽으로 이어지는 어두운 커튼 입구와 작은 창(오후 빛).
- 어둠 세력 표식(검은 고리)은 넣지 않습니다(이 공방은 어둠 세력과 무관).
시간대: 오후, 호박색 작업등과 창 빛. 색은 짙은 갈색·청회색에 놋쇠 금빛.

## 직접 확인 목록
1. 사람·글자·워터마크가 없는가? 2. 바닥 띠의 윗선이 위에서 약 82%에 또렷한가? 3. 작업대가 중앙 약간 오른쪽, 상판이 약 60% 높이이고 뒤쪽이 비어 있는가? 4. 왼쪽 끝에 닫힌 아치문 안쪽 면이 있는가? 5. 첨부 그림과 같은 그림체인가? 6. 3층 깊이가 느껴지는가?

## 재요청 문장 (그대로 복사)
- 사람이 보일 때: `그림 안의 사람과 인물 형태를 모두 지우고, 구도와 그림체는 바꾸지 말고 다시 그려 주세요.`
- 글자가 있을 때: `그림 안의 모든 글자·숫자·기호 문자와 로고를 지우고 나머지는 유지해 다시 그려 주세요.`
- 바닥 띠가 안 보일 때: `화면 아래 18%를 평평한 수평 바닥 띠로 만들고 윗선이 위에서 82% 지점에서 또렷하게 보이도록, 나머지는 유지해 다시 그려 주세요.`
