# 현실 미션 완료 기록 및 인증 설계 (2026-11-21)
## 이번 변경
- 신규 완료의 마음 경험은 미션 기본 점수만 지급. 평가 응답 여부와 응답값에 따른 가산 없음.
- 이미 저장된 경험, 활동 평가, 장식 보상은 수정하지 않음. 기존 경험이 새 기준 최대치보다 높아도 표시상 현재값을 유지.
## 후속 구현 명세 (미구현)
- 모든 30종은 자기보고로 완료/일부 수행 가능. 타이머·활동 설명·사진은 보조 기록이며 객관적 행동 검증이 아님.
- 권장 방식: P1/P5/E1/E2/E6 타이머; E4/M3/M4/M5/M6/A2/A4 활동 작성; E5/A3/A5/A6 선택형 사진; 나머지 자기보고. 모든 방식의 선택은 자율.
- 타이머는 중간 종료 가능, 최소 시간 강제 금지. 활동 작성과 도전·의미·만족도 평가는 선택.
- 사진은 기기 내부 보관에 한정; 서버 및 연구 데이터 전송 금지. 삭제 기능, 사용자 동의, 저장 한도와 오류 처리 필요. 메시지 캡처·인물·개인정보 제출 요구 금지.
- 보조 기록 방식과 수행 상태를 구분하고 기존 proof:self_report 호환 유지. 내용 없이도 같은 보상.
- 메인 퀘스트 진행/해금/완료와 현실 활동은 독립. 1막 연결은 별도 변경.
