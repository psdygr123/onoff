# 반복 현실 미션 및 개인별 수행 주기

최초 완료 시 지급했던 마음 경험과 갤러리 토큰은 반복 완료로 재지급하지 않습니다. 상태 done 유지. 반복 이력은 repeat:true 및 점수·토큰 0으로 날짜와 선택적 성찰·인증을 기록합니다.

주기 선택: 자유/매일/주간 횟수/요일 지정/2~30일 간격/일시 중지. 일정은 강제와 처벌이 없는 게임 내 계획 표시입니다. 브라우저 푸시 알림은 미구현이며 알림 체크는 향후 설정에 대비한 속성일 뿐입니다. 미수행 시 페널티 및 보상 회수 없음. 기존 저장의 missions.plans는 접근 시 빈 객체로 보완합니다.

휴식 미션은 별도 하루 한 번 규칙 유지. 이 통계는 실제 습관 형성이나 행복 향상에 대한 진단이 아닙니다.
