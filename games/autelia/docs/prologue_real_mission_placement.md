## 실행 규칙
- 제안은 한 번만 저장하며 재접속 후에도 중복 표시하지 않습니다.
- 현실 활동은 메인 퀘스트의 해금, 완료, 장면 전환에 절대 사용하지 않습니다.
- 부담감이 큰 습격·사망·유언·탈출 시에는 대화나 화면 전환을 막는 현실 활동 팝업을 표시하지 않습니다.
- 프롤로그 시작과 깃발 수락 시에만 모달을 사용하고 다른 제안은 모험일지 상단에 모읍니다.
- 퀘스트 연결은 심리학적 효능이 입증된 결과가 아니라 경험을 확장하기 위한 게임 디자인입니다.
- 기존 저장 파일의 현실 미션 ID와 실제 미션 기록은 그대로 유지합니다.

## 테스트
- 깃발 제안을 거절해도 게임 퀘스트 및 다음 장면 조건 유지
- 제안을 수락해도 기존 스토리 완료 플래그는 변하지 않음
- 신전·축제·포르투 노바 추천은 각 1회, 모험일지에서 확인 및 수락 가능
- 기존 캐릭터의 새 기록 데이터 누락 시 안전하게 초기화
- 자동 회귀검사와 갤러리·설문 관련 기존 테스트 통과 여부 확인
